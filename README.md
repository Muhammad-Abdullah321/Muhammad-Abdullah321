## 🧑‍💻 About Me

I'm a **Backend Developer** specializing in the **MERN stack**, building secure, scalable, and production-ready web applications from the database layer up through the API.

My core stack includes **Node.js, Express.js, FastAPI, MongoDB, and PostgreSQL**, with hands-on experience across the full request lifecycle — schema design, API architecture, authentication, and deployment. I work confidently across both greenfield builds and existing codebases, debugging complex backend issues and turning business requirements into clean, reliable APIs.

### 🎯 What I Do

🔧 **Backend & API Development**

- RESTful API design, architecture, and implementation
- Request validation, structured error handling, and API testing
- Cross-stack experience: Node.js/Express and Python/FastAPI

🔐 **Authentication & Security**

- JWT authentication and refresh-token handling
- Role-based access control (RBAC) and fine-grained authorization
- Password hashing, OTP verification, protected routes, and session management

🗄️ **Database Engineering**

- MongoDB and PostgreSQL schema design, querying, and optimization
- MySQL fundamentals
- Data migration between database systems (MongoDB → PostgreSQL)

⚛️ **Full Stack Capability (MERN)**

- React.js interfaces connected to Node.js/Express APIs
- End-to-end feature delivery from UI to database

### 💡 What Sets Me Apart

- End-to-end ownership: database schema → API → authentication layer → frontend integration
- Proven track record shipping SaaS-style backend modules — user/role management, payments, bookings, and staff workflows
- Strong debugging discipline across both legacy and modern codebases
